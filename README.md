# FM Academy

Site oficial da FM Academy, com duas experiências:

- página de vendas em `/`;
- página de link em bio em `/links`.

Os botões de conversão direcionam para o WhatsApp de Francisco Mairon com uma
mensagem específica para cada mentoria.

## Desenvolvimento

```bash
npm run install:ci
npm run build
```

Projeto responsivo desenvolvido com Next.js, React, Vinext e CSS próprio.
